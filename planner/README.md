# 우리 아이 주간 놀이 플래너 🌱

만 2세 전후 아이를 위한 **화면 없는** 주간 놀이 계획 도구입니다.
아이 개월 수에 맞는 오프라인 놀이를 요일별로 자동으로 짜주고,
인쇄해서 냉장고 등에 붙여두고 하나씩 해볼 수 있어요.

## 여는 방법

`planner/index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.
설치나 인터넷 연결이 필요 없습니다.

## 쓰는 법

1. **우리 아이** — 태어난 달을 고르면 개월 수에 맞는 놀이만 나와요 (기본 2024년 5월).
2. **관심 영역** — 감각·언어·소근육·대근육·인지·정서·음악·책 중 원하는 것만 켜기 (기본 전체).
3. **다시 뽑기** — 마음에 안 들면 버튼을 눌러 새 조합으로.
4. **인쇄하기** — 월~일 7일치 놀이 계획을 A4로 출력.

각 놀이 카드에는 **놀이 이름 · 노는 법 · 준비물(집에 있는 것) · 발달 포인트**가 담깁니다.

## 활용 팁

- 하루에 딱 하나면 충분해요. 5~15분, 아이가 흥미 있을 때.
- 같은 놀이를 반복해도 좋아요 — 아이는 반복으로 배웁니다.
- 준비물은 대부분 집에 있는 것. 없으면 비슷한 걸로 바꿔도 됩니다.
