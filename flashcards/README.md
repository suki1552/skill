# 우리 아이 플래시카드 만들기 🧸

만 2세 전후(2024년 5월생 기준) 아이를 위한 **화면 노출 없는** 학습 도구입니다.
아이가 보는 앱이 아니라, **부모가 인쇄용 플래시카드를 골라 만드는 도구**예요.
아이는 화면 대신 종이 카드와 부모의 목소리로 배웁니다.

## 여는 방법

`flashcards/index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.
설치할 것도, 인터넷 연결도 필요 없습니다.

## 쓰는 법

1. **주제 고르기** — 한글 낱말 · 숫자 · 동물 · 색깔 · 과일 · 몸, 또는 직접 입력
2. **카드 선택** — 보여줄 낱말만 켜고 끄기 (모두 선택/해제 가능)
3. **인쇄 설정** — 한 장에 4·2·1칸, 그림/영어/자르는 선 표시, 글자 크게
4. **인쇄하기** 버튼 → 브라우저 인쇄 창에서 A4로 출력

### 색칠 도안 (흑백) 모드

"색칠 도안" 스위치를 켜면 카드가 크레용용 흑백 도안으로 바뀝니다.

- 낱말은 **속이 빈 외곽선 글자** — 색칠하거나 따라 쓰기
- 그림은 연한 **밑그림** — 크레용으로 덧칠하기
- 색깔 카드는 **빈 칸** — 이름을 보고 그 색으로 칠하기
- 숫자 점은 **빈 동그라미** — 세면서 하나씩 칠하기

## 활용 팁

- 두꺼운 종이에 인쇄하고, 가능하면 코팅해서 오래 쓰세요.
- 한 번에 한 장씩 보여주며 또박또박 이름을 말해주세요.
- 아이가 직접 만지고 넘기게 두면 소근육 발달에도 좋아요.

## 바이브코딩으로 더 만들기

이 도구는 시작점입니다. 원하는 대로 말로 고쳐가며 키워보세요. 예:

- "숫자 카드를 20까지 늘려줘"
- "우리 아이가 좋아하는 낱말 목록을 기본으로 넣어줘"
- "카드 뒷면에 낱말 뜻을 적을 수 있게 해줘"
- "색칠용 흑백 도안 버전도 만들어줘"
